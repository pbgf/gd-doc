# @sailorgundam/gundam-recycle-list

> 高性能虚拟滚动列表组件

## 概述

`sailor-gundam-recycle-list` 提供高性能的虚拟滚动列表实现，通过只渲染可视区域内的列表项来大幅减少 DOM 节点数量，从而优化长列表的滚动性能和内存占用。

## 核心特性

- **虚拟滚动** — 仅渲染可视区域内的列表项
- **动态高度** — 支持列表项高度不固定的场景
- **高性能** — 大数据量下保持流畅滚动
- **回收复用** — 列表项 DOM 节点的回收与复用机制
