# @sailorgundam/gundam-preload-api-register

> v0.121.0 · 预加载 API 注册配置

## 概述

`sailor-gundam-preload-api-register` 提供接口聚合与预请求的注册配置。在页面加载前，将多个接口请求聚合并提前发出，以减少首屏数据加载时间，提升用户体验。

## 核心功能

- **接口聚合** — 将多个独立的 API 请求合并为一次网络请求
- **预请求** — 在页面渲染前提前发起数据请求
- **注册配置** — 声明式配置需要预加载的接口

## 构建

使用 Rollup 构建，输出浏览器可用的格式。
